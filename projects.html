Lost Items Management System (LIMS)

Helps a campus community report, match, and recover lost belongings without relying on a manual, walk-in lost-and-found desk.

LIMS is a full-stack lost-and-found platform developed for my final-year Computer Science project at Hawassa University. It lets campus users report lost or found items, search listings, and review potential matches. I led the backend work, including the MySQL data model, matching logic, and REST API for the React frontend.

Technologies

  • HTML
  • CSS
  • JavaScript
  • React
  • Node.js
  • MySQL
  • Git
  • GitHub

Key features

  • Guided reporting flow for both lost and found items, with category, location, and photo details
  • Keyword and category search across all open listings
  • Matching logic that compares new reports against existing ones and surfaces likely pairs for review
  • REST API (Node.js) connecting the React frontend to a normalized MySQL schema
  • Role-based team workflow: I owned the backend and API contract while teammates built the frontend against it

The challenge

The main challenge was designing the MySQL schema and matching logic to pair lost reports with found reports reliably, while four teammates built against my API.

What I learned

Defining the API request and response shapes early allowed the React frontend and backend to progress in parallel.
